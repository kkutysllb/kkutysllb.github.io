### 穷奇引擎
- 定义：项目的基础运行时/SDK，代号 QiongQi，是一个领域中立的独立多 Agent 框架，以 cache-first、去中心化编排的 HTTP/SSE 引擎为骨架，搭配可插拔的技能与工具体系，面向不同行业组装为生产力工具。在项目中作为 engines 列表的唯一条目，OClaw/KWorks/KCoder 三个产品均挂载在其下（parent: qiongqi）。
- 别名：QiongQi、穷奇

### 基础引擎
- 定义：指代项目中独立仓库、仅作 SDK/运行时的组件，与派生产品相对。当前仅有穷奇引擎一个基础引擎，其特点是直接暴露源码仓库、安装命令和开发者文档，而非仅提供成品安装包。
- 别名：engines

### 派生产品
- 定义：基于基础引擎构建的面向最终用户的桌面应用，必须通过 parent 字段挂在某个引擎下。当前包括 OClaw（桌面 Agent）、KWorks（Local-first AI Workspace）、KCoder（AI 编程工作台），它们只提供编译后的安装包下载，不包含源码仓库链接。
- 别名：products

### 闭源发布
- 定义：项目的发布模式目标——用户只能通过页面下载编译好的安装包（.dmg/.exe/AppImage 等），无法访问源码仓库。实现方式是移除 products.yml 中产品的 repo/homepage/install 字段，并在前端 renderProduct 中对这些字段做条件渲染（有则显示，无则隐藏）。
- 别名：闭源发布页面

### Release 自动同步
- 定义：通过 GitHub Actions 定时任务从各产品仓库的 GitHub Releases 拉取最新版本信息与下载链接，生成 data/releases/*.json 静态数据文件，供前端页面读取展示。每个产品对应一个 releases_file key，与 repos.txt 中的 owner/repo 映射。
- 别名：sync-releases、release 同步

### 桌面端
- 定义：产品版本类型之一，指跨平台的桌面应用程序，同时覆盖 macOS（Apple Silicon/Intel）、Windows、Linux 三平台，通过 GitHub Releases 分发 .dmg/.exe/.AppImage 等安装包。
- 别名：Desktop

### 本地优先
- 定义：KWorks 产品的核心理念定位——Local-first，强调数据存储在本地、模型是骨架、技能是血肉，同一引擎可随时切换为 coding copilot、研究分析师或创意工作室等不同角色。
- 别名：Local-first
